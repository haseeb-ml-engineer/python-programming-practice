# Python Programming Practice

A structured and well-documented workspace containing core Python programming implementations, data structures, and interactive data analysis exercises. This repository serves as a centralized sandbox for mastering core computer science problems and algorithm workflows.

---

## 📂 Repository Structure

The project code is organized logically into standalone modules and step-by-step interactive logs:

```text
├── practice-notebooks/
│   └── 01_print_function_in_python.ipynb   # Interactive exploratory code & data practice
├── python-practice-files/
│   ├── add_linked_list.py                  # Node logic and dynamic list additions
│   ├── binary_search.py                    # Optimized log(n) searching implementations
│   ├── bank_management_syztem.py           # Basic OOP state management simulation
│   └── [other core modules]                # Mathematical, character logic, & routing scripts
└── .gitignore                              # Development environment artifact exclusion rules
```

---

## 🛠️ Features & Implementations

### 1. Data Structures & Algorithms (DSA)
*   **Search Operations:** Low-level, iterative paradigms including optimal `binary_search.py`.
*   **Dynamic Structures:** Linked-List algorithms (`add_linked_list.py`) handling object nodes.
*   **Array Manipulation:** Base sequences and memory array access practices.

### 2. General Utility & Logic Scripts
*   **Conditionals & Loops:** Prime number evaluations, palindrome validations, leap year computations, and Armstrong number verification.
*   **Mathematical Computing:** Geometry formulas (`area_of_circle.py`, `area_of_triangle.py`), type conversion utilities (`celsius_to_fahrenheight.py`), and a modular standard calculator.
*   **Application Mockups:** Functional logic mimicking mini-systems (`bank_management_syztem.py`).

### 3. Interactive Notebook Explorations
*   Rich interactive environments under `practice-notebooks/` designed to log analytical progress, function behaviors, and print routines step-by-step.

## 🚀 Getting Started

### Prerequisites
Ensure you have Python 3.8+ and `jupyter` packages configured on your workstation.

### Local Installation & Running Environment
1. Clone this repository onto your machine:
   ```bash
   git clone https://github.com
   cd python-programming-practice
   ```

2. Run any standalone Python script directly from your terminal:
   ```cmd
   python python-practice-files/binary_search.py
   ```

3. Launch your local Jupyter instance to view interactive `.ipynb` files:
   ```bash
   jupyter notebook
   ```
